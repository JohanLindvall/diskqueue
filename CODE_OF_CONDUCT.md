# Code of conduct

diskqueue welcomes people of every background and experience level.
This code applies to issues, pull requests, code review, and other project
spaces.

## Work together respectfully

- Be patient with questions and explain the reasoning behind feedback.
- Critique ideas and code without attacking the person proposing them.
- Respect different experiences, communication styles, and accessibility needs.
- Accept corrections and take responsibility when your words cause harm.

Harassment, discriminatory remarks, threats, sexual harassment, deliberate
disruption, and sharing another person's private information are not welcome.

## Report a concern

Contact the maintainer privately at
[johan.lindvall@gmail.com](mailto:johan.lindvall@gmail.com).
Include links and context that help explain what happened. Avoid posting
sensitive details in a public issue. Reports will be handled as privately as
possible, with information shared only as needed to address the concern.

For security vulnerabilities in the library, use [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer may ask for a change in behavior, remove harmful content, close
disruptive contributions, or restrict participation. Responses should reflect
the severity and repetition of the behavior. A person affected by an
enforcement decision may contact the same address to request a review.
